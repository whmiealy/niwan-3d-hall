## 3. 代码结构
- `src/data/layout.js` 布局数据 + 碰撞盒（与展厅模型无关）；平面坐标原点在西北角，x 向东、y 向南；世界坐标 = (x-13, y-8)
- `src/data/exhibits.json` 28 个展品（编号/名称/分类/位置/模型路径）——**用户要求保持不变**
- `src/hall/ProceduralHall.js` 代码搭的展厅（同材质合并、小泥塑用 InstancedMesh）；`details.js` 道具辅助；`textures.js` Canvas 贴图；`SplatHall.js` 预留高斯泼溅；`config.js` 里 `HALL_MODE` 切换
- `src/exhibits/ExhibitLayer.js` 展品占位与点击；`src/controls/WalkControls.js` 漫游（WASD/拖动/摇杆/点地面）；`src/viewer/ExhibitViewer.js` 展品 3D 查看器
- `window.__app.snapshot(pos, target, w, h, fov)` 指定视角截图；`window.__app.exportGLB()` 导出整馆 glb
- `tools/save_server.py`：本地保存服务（127.0.0.1:8765），网页可把截图/模型 POST 到 `exports/`、`compare/`、`compare_raw/`；**需要时先在后台启动**
- `tools/pick_zone_frames.py`、`zone_fix.py`、`zone_sheet.py` 选帧；`tools/grid.py` 给图叠坐标网格读角点；`tools/extract_entrance_textures.py` 入口区贴图透视矫正提取
- 本地预览：`.claude/launch.json` 里的 `wenwuguan`（`npm run dev`，端口 5173）

## 4. 用户的工作方式（必须遵守）
按区域逐个精细重建，**每次只做一个区域，做完给用户看再做下一个**：
1. 清单里每一项都要在场景里出现，不许省略
2. 展板/海报/文字：从视频帧裁剪 + 透视矫正做贴图（OpenCV/Pillow）
3. 地面/墙面材质：从截图裁干净区域做可平铺贴图
4. 展柜结构正确：透明玻璃、边框、底座、层板
5. 灯具、吊顶造型建出来，灯光位置对应真实灯具
6. 自检：把相机摆到和视频帧相同的角度截图，与视频帧左右拼成 `compare/<区域名>.jpg`，逐项列不一致并修改，直到差异很小；把对比图和修改记录给用户看
7. 手机要流畅：单张贴图 ≤1024/2048，相同物体用 InstancedMesh；展品点击和 exhibits.json 不变
- 区域清单在 `docs/zones/01~08_*.md`，索引 `docs/zones/README.md`
