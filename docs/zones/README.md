## 素材与工具

- 抽帧：三个视频每秒 3 帧，存在 `frames_dense/v1`（IMG_5856，85 张）、`v2`（0G6A5533，715 张）、`v3`（IMG_5857，988 张）。这些帧不进仓库
- 挑帧：`tools/pick_zone_frames.py` 按区域时间段 + 清晰度（拉普拉斯方差）自动挑选，`tools/zone_fix.py` 剔除糊帧并补充指定帧，`tools/zone_sheet.py` 生成每个区域的总览图 `_sheet.jpg`
- 帧文件名 `v2_t0005.0.jpg` 表示视频 2 的第 5.0 秒；需要更高清的贴图时，按这个时间点从原视频重新取 4K 帧

## 和上一版相比发现的问题（重建时改正）

1. 前言墙下面不是 3D 泥塑浮雕，而是印刷画面（老艺人捏泥人 + 棕色波浪底边）
2. 曲线木博古架和窗台纸雕在**西南角**，不是东南角
3. 西墙南段还有一扇带窗帘的窗、一个安全出口灯和一个灭火器箱
4. 中央格栅里的筒灯是黑色深嵌筒灯，周边平顶是白色筒灯，墙上有明显的扇形光斑
5. 南墙下部（窗台以下）是竖条墙板 + 深棕石材窗台
6. 平柜有背面挡板和灯带，玻璃罩边缘泛绿；独立展台有红色指示灯和金属夹扣
