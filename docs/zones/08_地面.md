# 08 地面

- **参考帧**：`frames_dense/zones/08_地面/`（10 张），另有 `06 区 v3_t0232.3`、`02 区 v2_t0022.0`
- **关键帧**：
  - `v1_t0013.7`：灰蓝通道带的 L 形拐角
  - `v3_t0232.3`：大面积地砖 + 通道带
  - `v1_t0016.3`：反光

## 1. 地面材质

| # | 物件 | 细节 |
|---|---|---|
| 1.1 | 主地砖 | 米白抛光砖 0.8 × 0.8 `#E6DDD0`，有极淡的米黄云纹；砖缝 1~2 mm，浅灰；**反光很强**，能清楚看到筒灯倒影和展台倒影（**从 v3_t0232 裁一块干净区域做可平铺贴图**） |
| 1.2 | 灰蓝通道带 | 宽约 1.0 m（一块砖宽），颜色 `#AEB3BC`，同样是抛光砖；布局是一个“回”字形通道：沿北墙平柜前一条东西向带、沿中部展台区东西各一条南北向带，在中部以 L 形转角相接（v1_t0013） |
| 1.3 | 踢脚线 | 墙根有深棕木踢脚 8~10 cm；柜子底部是退进去的踢脚 |
| 1.4 | 楼梯口地面 | 楼梯下方是同款米白砖 |
